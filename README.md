# Трекер привычек

Адаптивное веб-приложение по скриншоту пользователя: тёмный фон, жёлтые молнии и цепочки выполнений. Версия 0.1.0 работает локально и офлайн после первого открытия. Supabase пока не подключён.

Источник дизайна: https://www.figma.com/design/mFzim43dKPdjzgGAExEK9k/?node-id=10342-61104

Репозиторий: https://github.com/SergeShchelokov/habbitsAtom

## Согласованные требования

- Приложение работает онлайн и офлайн.
- Пользовательские изменения сначала сохраняются в localStorage.
- После восстановления связи изменения синхронизируются с Supabase.
- В первой версии нет экрана регистрации и входа; пользователь один.
- Архитектура предусматривает добавление аккаунтов в будущем.
- Исходный код и версии хранятся в GitHub.
- Развёртывание выполняется на хостинге и домене пользователя.

## Текущий статус

Реализованы пустой экран, создание привычки с целью от 1 до 365 выполнений, одна отметка за локальный календарный день, отмена отметки за сегодня, счётчик, завершение цели и удаление с подтверждением. Пропуск дней не обнуляет прогресс. Выбор иконки отложен до следующей сборки.

Данные и очередь будущей синхронизации записываются одним документом в localStorage. Облачные запросы не выполняются; интерфейс честно показывает «На этом устройстве». Очередь подготовлена для v0.2, но не является готовым протоколом синхронизации.

На поддерживаемых браузерах Web Locks защищает запись из нескольких вкладок; в остальных браузерах используется синхронная запись с повторным чтением, без гарантии защиты от одновременных изменений нескольких вкладок. Данные привязаны к браузеру и адресу сайта. Очистка хранилища браузера удаляет локальные данные.

## Запуск и проверка

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Для проверки офлайн-запуска нужна production-сборка, а не Vite dev server:

```sh
npm run build
npm test
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

Откройте http://127.0.0.1:4173/ и дождитесь текста «Можно открывать без интернета». После этого можно отключить сеть или остановить сервер и перезагрузить страницу. Оболочка, шрифты и иконки берутся из локального кэша; привычки — из localStorage. Обновление оболочки применяется после закрытия всех вкладок приложения и нового запуска. На домене требуется HTTPS.

Статические файлы для хостинга: `dist/client/`. Будущее подключение Supabase и размещение на домене — отдельные этапы. Для будущей Android-версии доменная логика вынесена в `src/domain.mjs`; текущий выпуск — веб/PWA, APK пока нет.

## Проверки

`npm test` проверяет ежедневный лимит, отмену, пропуски, цель, очередь, удаление, повреждённые данные, отказ localStorage и отдачу ресурсов service worker, включая `Vary: Origin`. Сначала выполните `npm run build`: тест офлайн-кэша использует собранный service worker.

Логотип взят из предоставленного пользователем скриншота; UI-иконки — Phosphor, шрифт — локально поставляемый Inter. В runtime нет внешних шрифтов или CDN-запросов.
