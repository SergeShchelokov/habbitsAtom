# Трекер привычек

Веб-приложение по макетам «Т-Платформа». Стадия: согласование функционала и подготовка проекта; приложение ещё не реализовано.

Источник дизайна: https://www.figma.com/design/mFzim43dKPdjzgGAExEK9k/?node-id=10342-61104

Репозиторий: https://github.com/SergeShchelokov/habbitsAtom

## Согласованные требования

- Приложение работает онлайн и офлайн.
- Пользовательские изменения сначала сохраняются в localStorage.
- После восстановления связи изменения синхронизируются с Supabase.
- В первой версии нет экрана регистрации и входа; пользователь один.
- Архитектура предусматривает добавление аккаунтов в будущем.
- Исходный код и версии хранятся в GitHub.
- Развёртывание выполняется на хостинге и домене пользователя.
