# :21 — Хэбы, Фокус, Энергия, Идеи

Новая версия трекера на Vue 3, TypeScript, Vite, Tailwind и shadcn-vue.

- **Хэбы:** создай привычку с целью 21 выполнение, необязательным комментарием и лимитом 1–3 заряда за день. Сними последнюю отметку при необходимости. Пропущенный день не сбрасывает прогресс.
- **Фокус:** 15 или 30 минут, пауза и продолжение, обратный отсчёт в других разделах, мягкий сигнал после завершения при доступном звуке в браузере.
- **Энергия:** 10 настроений с анимацией мимики, комментарий до 500 символов, история. Старые отметки уровня энергии сохраняют шкалу 0–10.
- **Идеи:** текстовые и голосовые заметки. Зажми микрофон, чтобы записать до минуты, затем отпусти кнопку. Для записи в одно касание есть «Без удержания». Аудио можно прослушать после перезагрузки: оно хранится в IndexedDB этого браузера. Доступ к микрофону запрашивается только при записи и требует HTTPS или localhost. Интеграция Gemini пока не подключена.

Данные хранятся в браузере под новым ключом `hab21:tracker:v1`. Старый ключ `habbits-atom:v1` не читается и не меняется. Синхронизации между устройствами нет. После успешной установки кэша production-сборка открывается и без сети.

```sh
npm ci
npm run dev
npm run build
npm test
npm run test:sites
```

Сборка для GitHub Pages находится в `dist/client`. Конфигурация `components.json` указывает реестр и пути компонентов. MCP shadcn-vue подключается к Codex через `.codex/config.toml` доверенного проекта и нужен только для разработки.
