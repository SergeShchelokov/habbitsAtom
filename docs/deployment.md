# GitHub Pages

Цель публикации: https://sergeshchelokov.github.io/habbitsAtom/

Источник: ветка `main` репозитория SergeShchelokov/habbitsAtom. Настройки репозитория → Pages → Build and deployment → Source: **GitHub Actions**.

Workflow `.github/workflows/deploy-pages.yml` запускается при push в main и вручную. Он устанавливает зависимости по lockfile, собирает приложение, запускает тесты и публикует только `dist/client`. Исходники, QA-скриншоты, документация и серверный шаблон в артефакт сайта не входят. Новые токены и секреты для этой публикации не требуются: deploy использует временный GitHub Actions token.

Vite использует относительный `base: './'`, поэтому JS/CSS, иконки, манифест и service worker работают под путём `/habbitsAtom/`. Локальный запуск из корня также сохраняется.

После первого успешного открытия и завершения кэширования приложение открывается без сети. Обновлённая оболочка применяется после закрытия всех вкладок приложения и следующего открытия.

Локальный адрес и GitHub Pages — разные origin. Привычки из localStorage на localhost не появляются на опубликованном адресе автоматически. Облачная синхронизация пока не подключена; публикуется только приложение, пользовательские записи остаются в браузере пользователя.

Результат публикации подтверждается успешным deploy job и проверкой приложения по публичному адресу. До этого адрес является ожидаемым, а не подтверждением готового сайта.
