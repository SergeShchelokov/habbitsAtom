# MVP v0.1

Пользователь согласовал 19 октября 2026: сначала веб, затем Android; функционал первой версии максимально простой.

1. Первый запуск — пустой экран с молнией, дружелюбным текстом и кнопкой добавления.
2. Создание — название до 80 символов и цель от 1 до 365 выполнений, по умолчанию 40. Выбор иконки — позже.
3. 40 выполнений означает 40 отметок в разные календарные дни. Количество физических повторений можно указать в названии.
4. Строка привычки — счётчик и название слева, действие за сегодня и нумерованная цепочка справа. На телефоне цепочка располагается под названием и прокручивается горизонтально.
5. Одна отметка за день по локальной дате устройства; сегодняшнюю отметку можно отменить. Пропуски не обнуляют прогресс. Назад во времени отметки не ставятся.
6. Достижение цели — состояние завершения; новые отметки сверх цели недоступны.
7. Удаление — подтверждение, затем удаление из списка; запись помечается удалённой для будущей синхронизации.
8. Сохранение — localStorage, включая очередь операций. Сбой записи не выдаётся за успех. Повреждённое хранилище не перезаписывается; есть выгрузка исходной копии.
9. Работа без сети — PWA-кэш после первого успешного открытия production-сборки. Полноценная синхронизация Supabase — v0.2 после подключения проекта и согласования защиты доступа.

Напоминания, календарь, серии дней, графики, расписания, редактирование, категории и аккаунты в v0.1 не входят.
