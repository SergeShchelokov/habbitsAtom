# Ветки проекта

- `main` — версия, опубликованная на GitHub Pages.
- `test` — новые функции и UX-правки для проверки перед публикацией.

Текущая итерация ведётся в `test`. Команда «переключись на тест» означает переход на ветку `test`; «переключись на main» — переход на `main`. Само переключение ничего не публикует. Изменения переносятся из `test` в `main` только по отдельной команде пользователя опубликовать или перенести их.

Workflow в `test` запускает сборку и тесты при push. Публикация и загрузка артефакта Pages разрешены только для `refs/heads/main`, включая ручной запуск workflow. Тестовая ветка пока не имеет отдельного публичного адреса: проверка доступна локально. Данные localStorage зависят от адреса сайта, а не от имени Git-ветки; локальные версии на одном origin используют одно хранилище.

Git-команды:

```sh
git switch test
git switch main
```

При переключении сохранять незакоммиченные изменения. Не применять reset/clean или удаление данных ради перехода между ветками.
