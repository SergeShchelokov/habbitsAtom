# :21 — проектные правила

- Пользователь попросил начать приложение с чистого кода. Новая реализация — Vue 3, TypeScript и shadcn-vue. Фирменные цвета: тёплый тёмный #1C1A1D, жёлтый #FFD453 и кремовый #F1F0E9 из Figma, узел 183:732. Используй экспортированный логотип в `public/assets/figma/logo.svg`; SVG-ассеты лежат локально. Круговой индикатор — собственный SVG; сохранена иллюстрация с монетой-молнией для пустого экрана.
- Правила ХЭБа: 21 выполнение, предел 1–3 в локальный календарный день, отмена последней отметки и отсутствие штрафа за пропуск. Комментарий до 200 символов. Фокус — 15/30 минут, Энергия — 0–10 и комментарий до 500 символов, Идеи — локальные заметки.
- UI в `src/`, доменные функции в `src/tracker.ts`. Хранилище новой версии отдельное; данные первой версии не удалять.
- Сохраняй относительные статические пути для GitHub Pages. CI публикует только из main. Для проверки: `npm run build`, `npm test`, `npm run test:sites`; перед визуальной сдачей открой локальный предпросмотр, если он доступен.
- Сохраняй `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs` и `tests/sites-worker.test.mjs` для совместимости со сборкой Sites.
